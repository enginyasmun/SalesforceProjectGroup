# HR Management Application

## Business objective
Build a secure Salesforce recruitment solution for HR Managers, Candidates, Interviewers, administrators, and external users.

## Major capabilities
- Recruitment data model and access controls
- Validation and duplicate management
- Reports and management dashboard
- Apex trigger, service, batch, scheduling, and tests
- Web-to-Lead, approval, record-triggered Flow, and email automation
- Address verification and Apex REST integration
- Lightning Web Components and Screen Flow
- Experience Cloud pages and external access
- Email-to-Case and customer-reply notifications

## Professional expectations
Every implementation must include evidence, testing, security analysis, business reasoning, and an explanation of personal contribution. A feature is not complete merely because it works for an administrator.
